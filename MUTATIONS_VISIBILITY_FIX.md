# МЯУ-МУТАЦИИ: исправление заметности способностей, 19.10.2026

## Жалоба
Игрок сообщает: «Эффекты не работают».

## Проверенные факты
- На опубликованной GitHub Pages версии `8c3b0e4` проверен мобильный Chrome в изолированной браузерной сессии с фиксированным RNG.
- Пятый бросок создал мутанта Жиробаса; сохранённый снимок сначала показал `armed`, затем `active`.
- Ошибок JavaScript при воспроизведении не обнаружено.
- Исходный визуальный эффект у Жиробаса был практически незаметным: только маленькая метка, без отдельной анимации начала способности. Для Призрака отсутствовало отдельное уведомление о начале/окончании, а у Пружины/Магнита/Ниндзя кольцо отображалось очень коротко.

## Исправление
- Все пять видов получили постоянные цветные ауры до расходования/завершения способности:
  - Призрак: двойное голубое кольцо и фазовая прозрачность;
  - Жиробас: толстый золотой контур, подчёркнутый низ;
  - Пружина: пульсирующие бирюзовые кольца при ожидании удара;
  - Ниндзя: вращающийся пунктир;
  - Магнит: розовый контур и широкий пунктирный радиус поля при активном притяжении.
- Для Призрака и Жиробаса генерируются события активации; у Жиробаса добавлен ограниченный по частоте сигнал сильного столкновения.
- Для Пружины, Ниндзя и Магнита уточнены типы событий, радиус и анимация; уведомления на русском языке.
- Увеличено время видимости импульсных колец; события отображаются при срабатывании способности, а не только при её выпадении.
- Версионированы все обновлённые модули и поднят кеш PWA до v9. Вероятность появления мутации сохранена ровно 10%, начиная с пятого броска, как было согласовано.

## Проверка
- `node --check game.mjs`
- `node --check mutation_effects.mjs`
- `node --test test_mutation_effects.mjs test_mutations.mjs test_absolute_mur.mjs test_game_state.mjs`
- `py -3 test_browser_mutations.py` — headless Chrome с мобильным viewport; специальный монитор подсчитывает реальные Canvas2D штрихи золотой ауры Жиробаса (проверка отличает от простого наличия mutation metadata).
- `git diff --check`

## Ограничения
Это исправление замечаемости физических эффектов, а не увеличение вероятности выпадения. Если кот подходящего уровня не встретил нужную физическую ситуацию (например, Пружина не получила достаточно сильный удар или рядом с Магнитом нет обычного кота того же уровня), заявленный физический эффект может не переместить соседей. Для редких мутаций это нормальное игровое условие. Реальное тестирование на физическом iPhone и Android по-прежнему необходимо.
