# МЯУ — слияние котов

Публичная версия с увеличенным полем на 25%, уменьшенными крупными персонажами, тремя Лапами помощи, секретным Демирчадом и победой при слиянии двух Демирчадов.

Статическая игра. Запускать через статический HTTP-сервер.


## PWA

Android: открыть ссылку в Chrome → меню → Установить приложение.

iPhone: Safari → Поделиться → На экран «Домой».

Offline: после первого открытия онлайн файлы игры будут доступны офлайн (в пределах политики хранения браузера).

Важно: публикация публичная, пароль и ограничение доступа не настроены.
