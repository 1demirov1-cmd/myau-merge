# «МЯУ» — удаление Пружины, 19.10.2026

- Пружина полностью исключена из генератора, физических способностей, UI/звуков и актуальных тестов. Единственное упоминание бывшего типа в работающем коде — одноразовая миграция старых сохранённых игр: кот становится обычным, сохраняя уровень и положение.
- Кот-маньяк — новый пятый мутант (25% среди мутантов). Маленький знак ножа; одноразово удаляет кота **другого** уровня, на которого приземляется сверху. Кот того же уровня объединяется по обычным правилам; при временной блокировке слияния удаление также запрещено. Финальные Камиллкачад и Демирчад защищены.
- Магнит: радиус 7 собственных радиусов, усиленное ускорение. Притягивает обычных котов того же уровня, непосредственно через физику; может не сработать без подходящих целей.
- Всплывающее **название** каждого вида мутации показывается только один раз за партию. Состояние показанных названий сохраняется, в том числе при перезагрузке и отмене броска. Короткие сообщения о действиях не повторяют названия.
- Вероятность мутантов 10%, первые 4 броска обычные; не более 3 активных.

Проверки: шесть Node-тестов, сценарии Маньяка (удаление, обычное слияние, запрет удаления при lock, сохранение финальных боссов), миграция старых сохранений, нормальный финал; браузерные тесты мобильного Chrome (отображение значка ножа, однократное название, сохранение/отмена, анимации Ниндзя и Магнита, отсутствие JS ошибок). Ручные испытания на физических телефонах пока не выполнялись.
